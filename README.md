# Alacrity-Launcher
A simple launcher for Terraria that supports older versions up to 1.2

The launcher requires [.NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) to function.

You are required to have purchased a valid copy of Terraria on Steam or it will not work.
When downloading a specific version of Terraria for the first time, you will be prompted for for your password, do not worry the password does get entered even though nothing shows up, your password also isn't stored on the launcher, it's forwarded directly to Steam via SteamCMD.

This launcher only works on Windows.
